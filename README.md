# Moonbay 🌙

A cozy, dark-themed personal den built with React, TypeScript, and Vite.

## Features
- Personal den dashboard
- Moon phase overview and moon journal
- Customizable territory markers
- Editable den and pack names
- Theme accent and widget settings
- Local browser storage for personal settings and journal entries

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

For Vercel, use the Vite preset, build command `npm run build`, and output directory `dist`.

This is a separate project. It does not modify the `Denworks-` repository.
